# Datenbanken & SQL (DPA)

## 1. Datenmodellierung
- Relationale Datenbanken: Tabellen, Schlüssel, referenzielle Integrität.
- Star-Schema im Data Warehouse: zentrale Faktentabelle + Dimensionstabellen.

## 2. SQL für Analyse
- SELECT mit WHERE, GROUP BY, HAVING, ORDER BY.
- Aggregationen: COUNT, SUM, AVG, MIN, MAX; DISTINCT für eindeutige Werte.
- JOINs zur Kombination mehrerer Tabellen.

## 3. ETL & Data Warehousing
- **ETL**: Extract, Transform, Load.
- OLTP (operative Systeme) vs. OLAP (Analyse).
- Big-Data-Merkmale: Volume, Velocity, Variety (3 Vs).

## 4. Datenqualität
- Dimensionen: Korrektheit, Vollständigkeit, Aktualität, Konsistenz, Eindeutigkeit.
