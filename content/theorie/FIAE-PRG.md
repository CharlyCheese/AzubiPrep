# Programmierung & OOP (FIAE)

## 1. Grundlagen
- Variablen, Datentypen, Operatoren und Kontrollstrukturen sind die Basis jeder Programmierung.
- Java: `int` (32 Bit), `long` (64 Bit), `double`, `boolean`, `String`.
- Python: dynamische Typisierung, `list`, `tuple`, `set`, `dict`.

## 2. Objektorientierung
- **Klasse** = Bauplan, **Objekt** = Instanz einer Klasse.
- **Kapselung**: Attribute privat, Zugriff über Methoden (Getter/Setter).
- **Vererbung** (`extends`): Subklasse erbt von Superklasse („ist-ein"-Beziehung).
- **Polymorphie**: Gleiche Schnittstelle, unterschiedliche Implementierung (Überschreiben/Overriding).
- **Abstraktion**: abstrakte Klassen und Interfaces definieren Verträge.

## 3. Fehlerbehandlung
- `try`–`catch`–`finally` für Ausnahmen (Exceptions).
- `NullPointerException`: Zugriff auf null-Referenz.

## 4. Prüfungstipps
- OOP-Begriffe an kleinen Codebeispielen erklären können.
- Unterschied Interface ↔ abstrakte Klasse nennen können.
- Typische Fachbegriffe (Konstruktor, Attribut, Methode, Instanz) sicher verwenden.
