# Hardware, Virtualisierung & Cloud (FISI)

## 1. Server-Hardware
- CPU, RAM (schneller Zwischenspeicher), Speicher (HDD/SSD/NVMe über PCIe).
- RAID-Stufen: RAID 0 (Striping, kein Schutz), RAID 1 (Spiegelung), RAID 5 (Striping + Parität), RAID 6.

## 2. Virtualisierung
- **Hypervisor**: Software zur Verwaltung virtueller Maschinen (VMware ESXi, Hyper-V, KVM).
- **VM**: eigenes Gast-OS auf virtualisierter Hardware.
- **Container** (Docker): teilen Host-Kernel, leichtgewichtig, schnell startbar.

## 3. Cloud-Computing
- Servicemodelle: IaaS, PaaS, SaaS.
- Betriebsmodelle: Public, Private, Hybrid, Community Cloud.
- Vorteile: Skalierbarkeit, elastische Ressourcen, OPEX statt CAPEX.

## 4. Betrieb
- Verfügbarkeit (Uptime in Prozent), Backup-Strategien (Voll/inkrementell/differentiell), 3-2-1-Regel.
