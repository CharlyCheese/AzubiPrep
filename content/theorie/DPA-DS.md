# Data Science & KI-Grundlagen (DPA)

## 1. ML-Pipeline
Daten sammeln → bereinigen → explorieren → modellieren → evaluieren → deployen.

## 2. Lernverfahren
- **Überwacht**: Klassifikation (Spam/kein Spam), Regression (Preis schätzen).
- **Unüberwacht**: Clustering (Kunden gruppieren), Assoziation.
- **Bestärkend**: Agent lernt durch Belohnung.

## 3. Modellqualität
- Accuracy (Anteil korrekt klassifizierter Fälle), Precision, Recall.
- **Overfitting**: Modell lernt Trainingsdaten „auswendig" und verallgemeinert schlecht.
- Train-Test-Split: Modell auf unbekannten Daten prüfen.

## 4. Werkzeuge & Ethik
- Python: pandas (Dataframes), matplotlib/Seaborn (Visualisierung), scikit-learn (ML).
- Bias in Trainingsdaten kann diskriminieren → faire, transparente KI.
