# Betriebssysteme & Server (FISI)

## 1. Aufgaben eines Betriebssystems
- Kernel verwaltet Prozesse, Speicher, Geräte, Dateisysteme.
- Dateisysteme: NTFS (Windows), ext4 (Linux), APFS (macOS).

## 2. Windows Server & Verzeichnisdienste
- **Active Directory**: zentrale Verwaltung von Benutzern, Gruppen, Computern und Gruppenrichtlinien (GPO).
- Domänenmitgliedschaft, Rechtevergabe über Gruppen.

## 3. Linux-Grundlagen
- Wichtige Kommandos: ls, cd, ps, grep, chmod, chown, sudo.
- Dienste: SSH (verschlüsselte Fernwartung, Port 22), Apache/Nginx, DHCP, DNS.

## 4. Administration & Skripting
- PowerShell (Windows), Bash (Linux) für Automatisierung.
- Monitoring: Status- und Ereignisdaten erfassen (SNMP, Syslog).
- Backups: Voll-, inkrementelle, differentielle Sicherung.
